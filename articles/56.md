# Как измерять точно: меры, весы и часы

Не измерив, невозможно ни торговать, ни строить, ни делать одинаковые детали. Мера должна быть общей, иначе каждый обманывает по-своему.

Длину сравнивают с эталоном. Массу измеряют весами, сравнивая с гирей. Время определяли по солнцу, потом по песку, воде, маятнику. Маятник качается с постоянным периодом, это основа точных часов. Для моряка точные часы нужны, чтобы определить долготу: он сравнивает местное время с временем порта отплытия. Любой прибор проверяют по эталону, иначе ошибка накапливается.

Маятниковые часы построил Христиан Гюйгенс около 1656 года. Корабельный хронометр Джона Харрисона XVIII века позволил определять долготу в море. Метрическую систему приняла Франция в 1790-х годах, с тех пор она распространилась почти на весь мир.

Точные меры нужны и для того, чтобы увидеть то, что глазу недоступно. Следующий вопрос: как сделать стекло и линзу.

**Главная мысль:** Мера работает, когда она одна для всех и когда её можно проверить.
